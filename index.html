    Retrouver Elanos sur tous mes appareils

    Choisissez un identifiant (votre e-mail) et un mot de passe. Sur un autre appareil, entrez les mêmes : vous retrouvez votre parcours, vos CV, vos candidatures et votre suivi.

    À lire avant de commencer. Vos données sont verrouillées avec votre mot de passe, sur votre appareil, avant d'être envoyées. Personne d'autre ne peut les lire, pas même Elanos. Conséquence : si vous oubliez ce mot de passe, vos données en ligne sont perdues pour toujours, personne ne peut les récupérer. Gardez-le dans un endroit sûr (le gestionnaire de mots de passe de votre téléphone, par exemple).

    Synchronisation activée

    Se déconnecter garde vos données sur cet appareil et en ligne. Le code d'accès à Elanos n'est jamais synchronisé : il reste propre à chaque appareil.

    Vos données et vos droits

    Ce qui est enregistré en ligne : un bloc de données chiffré sur votre appareil avec votre mot de passe (parcours, CV, lettres, suivi, objectifs), un identifiant haché dérivé de votre e-mail, et des dates techniques. Elanos ne reçoit jamais votre e-mail, votre mot de passe ni le contenu lisible de vos documents.

    Hébergement : Cloudflare. Durée : tant que vous utilisez la synchronisation ; sans aucune connexion pendant 400 jours (environ 13 mois), le bloc est supprimé automatiquement.

    Vos droits : supprimer vos données en ligne à tout moment avec le bouton ci-dessus ; récupérer une copie avec « Exporter mes données » ci-dessous. Pour toute question : jalon.emploi@gmail.com (responsable du service : Maxence Pemjean).
